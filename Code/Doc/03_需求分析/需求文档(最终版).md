## 一、项目概述

### 1.1 项目背景

本项目为工业气体传感器及火灾报警企业的官方网站系统，用于对外展示企业能力、产品信息及行业解决方案，支持客户线索收集与后台管理，**并提供 IoT 设备接入、实时数据监控与智能报警管理**。

### 1.2 项目定位

- ToB 企业官网
- 内容展示系统
- 客户线索收集系统
- 后台内容管理平台
- **IoT 设备监控平台**
- **智能报警管理系统**

### 1.3 项目范围（V1.6）

本版本包含：

- 官网展示（首页、产品中心、解决方案、新闻动态、关于我们、联系我们）
- 产品展示与管理（多图 + 属性表 + 分类筛选）
- 解决方案/新闻展示与管理（富文本编辑器 + 封面图）
- 客户留言收集与管理（三态流转 + 员工指派 + 批量处理）
- 客户注册与登录（JWT 双 Token + 验证码）
- 员工管理（CRUD + 状态管理 + 角色枚举）
- 工单管理（创建/指派/完成，支持告警自动创建）
- 评论系统（多态关联：产品/内容/工单）
- AI 智能助手（DeepSeek + LangChain4j 流式 SSE + 嵌入搜索）
- 客户360全景（客户维度的设备/告警/工单/留言聚合）
- 文件下载中心（资料上传/下载，公开/私有权限）
- 操作日志（AOP 自动审计：操作人/IP/目标/详情）
- 系统配置（Key-Value 配置管理 + Redis 缓存）
- **设备管理**（CRUD + 四态状态机 + API Token 认证）
- **设备数据接入**（device-collector 微服务 + device-simulator 模拟器）
- **报警规则引擎**（阈值/离线/低电量，滑动窗口触发）
- **报警记录管理**（确认/解决/关闭，四态流转 + 关联工单/通知）
- **通知记录**（站内通知 + SMS/Email 双通道 + 重试机制）
- **数据大屏**（WebSocket 实时推送 + ECharts 趋势图 + Redis 缓存）

不包含：

- 电商系统/支付
- 真实硬件设备对接（使用模拟数据）
- 真实短信/邮件发送（Mock 实现，预留接口）
- 移动端 APP

## 二、项目目标

### 2.1 MVP目标

- 实现企业官网上线
- 支持产品展示
- 支持客户线索收集
- 支持后台内容维护

### 2.2 后续演进方向（非本期范围）

- 电商能力
- IoT设备接入
- 智能分析能力
- 系统架构升级

### 2.3 非功能需求（验收标准）

#### 2.3.1 性能要求

| 指标             | 要求                           |
| ---------------- | ------------------------------ |
| 官网首屏加载时间 | < 2秒（4G网络环境）            |
| 表单提交响应时间 | < 3秒                          |
| 后台列表分页     | 数据超过20条时需分页，每页20条 |

#### 2.3.2 安全要求

- 后台管理路径需做登录校验，未登录不可访问
- 所有前后端接口需做防SQL注入和XSS攻击处理
- 管理员密码存储必须加密（不可明文）
- 登录失败超过5次，账号锁定30分钟

#### 2.3.3 兼容性要求

- 前端需适配主流浏览器：Chrome（最新两版）、Safari（最新两版）、Edge（最新版）
- 需支持移动端自适应（响应式设计），适配宽度：375px - 1920px

#### 2.3.4 数据埋点（可选）

- 统计“咨询”按钮点击量
- 统计表单提交成功率
- 统计页面访问量（PV/UV）

## 四、业务流程

### 4.1 核心流程

```
用户访问官网
    ↓
浏览产品 / 解决方案
    ↓
产生需求
    ↓
提交联系信息
    ↓
后台查看并处理
```

### 4.2 产品浏览流程

```
进入产品列表
    ↓
筛选产品（按分类）
    ↓
查看产品详情
    ↓
点击咨询 / 跳转联系页面
```

**空状态处理：** 当筛选结果为空时，展示“暂无匹配产品”提示，并引导用户查看其他分类。

### 4.3 客户线索流程

```
填写表单
    ↓
提交信息
    ↓
系统记录
    ↓
后台查看
    ↓
标记处理状态
```

**异常处理：**

- 网络超时：提示“网络异常，请稍后重试”
- 重复提交：按钮在提交后进入加载状态，禁止重复点击

### 4.4 后台管理流程

```
管理员登录
    ↓
进入后台系统
    ↓
管理产品 / 内容
    ↓
查看留言
    ↓
更新处理状态
```

#### 5.1.4 联系模块（核心）

##### （1）提交表单

**输入字段：**

| 字段名   | 类型         | 必填 | 校验规则                   |
| -------- | ------------ | ---- | -------------------------- |
| 姓名     | 文本输入框   | 是   | 不超过50字符               |
| 电话     | 手机号输入框 | 是   | 必须为11位手机号格式       |
| 需求描述 | 多行文本框   | 是   | 不少于5字符，不超过500字符 |

**业务规则：**

- 所有字段不能为空
- 电话必须符合手机号格式（1开头的11位数字）
- 同一手机号60秒内仅允许提交一次（防刷）
- 同一IP每分钟最多提交3次

**处理逻辑：**

1. 前端校验字段合法性
2. 后端再次校验
3. 校验通过后保存数据
4. 返回结果给前端

**反馈结果：**

| 场景           | 提示信息                     |
| -------------- | ---------------------------- |
| 成功           | “提交成功，我们将尽快联系您” |
| 字段校验失败   | 对应字段下方红色提示具体错误 |
| 60秒内重复提交 | “您已提交过，请稍后再试”     |
| 网络异常       | “网络异常，请稍后重试”       |

**交互细节：**

- 提交按钮点击后进入加载状态，显示“提交中...”，禁止重复点击
- 成功后清空表单，显示成功提示
- 失败后保留已填内容，方便用户修改

##### （2）联系方式展示

- 公司电话
- 公司地址
- 邮箱

### 5.2 后台功能

#### 5.2.1 登录与权限

**登录**

**输入字段：**

| 字段名 | 类型       | 必填 |
| ------ | ---------- | ---- |
| 用户名 | 文本输入框 | 是   |
| 密码   | 密码输入框 | 是   |

**业务规则：**

- 用户名必须存在
- 密码必须正确
- 连续登录失败5次，账号锁定30分钟

**结果：**

| 场景     | 处理                                      |
| -------- | ----------------------------------------- |
| 成功     | 进入后台首页，存储登录态（Session/Token） |
| 失败     | 提示“用户名或密码错误”，显示剩余尝试次数  |
| 账号锁定 | 提示“账号已锁定，请30分钟后重试”          |

**权限控制：**

- 三级角色体系：
  - `ADMIN`：全部后台管理权限（产品/内容/分类/留言/工单/员工/用户/设备/告警/通知/系统配置/操作日志/客户360/文件下载）
  - `STAFF`：员工后台权限（工单处理/留言处理/设备巡检/告警确认/通知查看）
  - `USER`：客户自助权限（查看我的设备/设备数据/告警记录/提交工单/个人信息）
- 未登录状态访问后台任何页面，均跳转至登录页

#### 5.2.2 产品管理

##### （1）产品列表

**展示字段：**

| 字段     | 说明                   |
| -------- | ---------------------- |
| 产品名称 | -                      |
| 所属分类 | -                      |
| 状态     | 上架/下架              |
| 创建时间 | 格式：YYYY-MM-DD HH:mm |
| 操作     | 编辑 / 删除 / 上下架   |

**列表规则：**

- 默认按创建时间倒序排列
- 支持按产品名称模糊搜索
- 支持按分类筛选
- 支持按状态筛选（全部/上架/下架）
- 超过20条分页，每页20条

**删除规则：**

- 删除为逻辑删除（下架状态），非物理删除
- 删除后前台不再展示
- 删除操作需二次确认弹窗：“确认删除该产品？”

##### （2）新增产品

**输入字段：**

| 字段名   | 类型         | 必填          | 说明                            |
| -------- | ------------ | ------------- | ------------------------------- |
| 产品名称 | 文本输入框   | 是            | 不超过100字符                   |
| 所属分类 | 下拉选择     | 是            | 从分类列表中选择                |
| 封面图   | 图片上传     | 是            | 建议尺寸 800×600px              |
| 产品图片 | 多图上传     | 是（至少1张） | 支持多张，建议尺寸 1200×800px   |
| 产品描述 | 富文本编辑器 | 是            | 支持图文混排                    |
| 产品参数 | 键值对表单   | 否            | 动态添加参数行（参数名+参数值） |
| 状态     | 开关         | -             | 默认上架                        |

**业务规则：**

- 产品名称不能为空且不能与已有产品重名
- 分类必须存在
- 图片格式支持：JPG、PNG、WebP，单张不超过2MB

**结果：**

| 场景 | 处理                           |
| ---- | ------------------------------ |
| 成功 | 提示“新增成功”，返回产品列表   |
| 失败 | 提示具体错误原因，保留已填内容 |

##### （3）编辑产品

- 支持修改所有字段
- 修改后立即生效（前端实时更新）
- 编辑页面结构与新增页面相同，预填已有数据

##### （4）删除产品

- 规则：逻辑删除（状态变为“下架”）
- 删除操作需二次确认：“确认删除该产品？删除后前台将不再展示。”

| 封面图 | 图片上传     | 否   | 建议尺寸 1200×600px |
| 状态   | 开关         | -    | 默认发布            |

**列表规则：**

- 默认按创建时间倒序排列
- 支持按分类筛选
- 支持按标题模糊搜索

**删除规则：**

- 删除操作需二次确认
- 删除后前台不再展示（逻辑删除）

未处理 → 已处理

text

## 六、数据对象（概念层）

系统涉及核心数据对象：

| 对象             | 说明          | 关键属性（概念层）                                           |
| ---------------- | ------------- | ------------------------------------------------------------ |
| 用户（管理员）   | 后台登录用户  | 用户名、密码（加密）、角色、状态                             |
| 产品             | 企业产品信息  | 名称、分类、封面图、图片集、描述、参数、状态（0=下架/1=上架）、排序号、创建时间、更新时间 |
| 分类             | 产品/内容分类 | 名称、类型（产品分类/内容分类）、排序号、状态                |
| 内容（解决方案） | 解决方案文章  | 标题、分类、封面图、内容、状态（0=草稿/1=发布）、创建时间、更新时间 |
| 留言             | 客户线索      | 姓名、电话、需求描述、处理状态（PENDING/IN_PROGRESS/PROCESSED）、指派员工、管理员备注、提交时间、提交IP |
| **设备**         | **IoT 设备**  | **序列号、名称、型号、客户UUID、气体类型、量程、报警阈值、状态（NORMAL/ABNORMAL/OFFLINE/MAINTENANCE）** |
| **设备数据点**   | **遥测数据**  | **设备UUID、时间戳、浓度、电池、温度、湿度、信号强度** |
| **报警规则**     | **报警配置**  | **名称、类型（THRESHOLD/OFFLINE/LOW_BATTERY）、适用设备、阈值、持续窗口、严重级别、自动创建工单** |
| **报警记录**     | **报警事件**  | **设备UUID、规则UUID、类型、严重级别、浓度、阈值、消息、状态（PENDING/CONFIRMED/RESOLVED/CLOSED）、确认人、解决人** |
| **通知记录**     | **通知发送**  | **报警UUID、接收人、通道（IN_APP/SMS/EMAIL）、内容、状态、重试次数** |

> 注：完整数据结构（字段类型、长度、索引等）在系统设计文档中定义。
>
> **属性说明**：
> > - **业务类型**：标识内容所属的业务模块。当前版本主要为 `SOLUTION`（解决方案），后续可扩展 `NEWS`（新闻动态）等。**此属性与“分类”彼此独立**。
> > - **分类**：标识内容归属的具体行业或领域（如：石油、化工、制造业）。
> > - 即：
> > - ContentType（type）：
> >   \- 表示内容业务类型（解决方案 / 新闻）
> >
> >   Category：
> >   \- 表示内容分类（行业/产品分类）
