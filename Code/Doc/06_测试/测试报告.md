## 三、QA 审查记录

### 3.1 审查机制

```
board-b 任务完成
       ↓
   QA Agent 扫描 (每 5min)
       ↓
   ┌─ 正确性审查：逻辑是否正确
   ├─ 安全审查：SQL 注入、XSS、认证
   ├─ 可读性审查：命名、注释、结构
   └─ 测试审查：是否有对应测试
       ↓
   PASS → comment "QA reviewed: PASS"
   FAIL → comment "FAIL — 具体问题"
       ↓
   L2 组长等待所有子任务 QA PASS → 汇总
```

### 3.2 主要问题及修复

| 编号 | 问题 | 严重度 | 修复 |
|------|------|--------|------|
| BUG-01 | AuthServiceImpl 未注入 LoginLockRepository | HIGH | 补 `@Autowired` |
| BUG-02 | RedisTemplate<String, Integer> 类型不匹配 | HIGH | 改为 `RedisTemplate<String, String>` |
| BUG-03 | 通知触达：Alert CONFIRMED 后未更新 notification | MEDIUM | 补充状态同步逻辑 |
| BUG-04 | WorkOrder completedAt 未在 COMPLETED 时写入 | MEDIUM | 补 `completedAt = LocalDateTime.now()` |
