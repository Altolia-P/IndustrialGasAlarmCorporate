## 二、生产依赖（运行时必须）

### 2.1 框架核心

#### vue ^3.5.13

| 项目 | 说明 |
|------|------|
| 用途 | 前端 UI 框架，所有组件基于 Vue 3 Composition API + `<script setup>` 编写 |
| 在项目中的使用 | 全部 15 个 `.vue` 文件、4 个 composables、1 个 store |
| 关键 import | `ref`, `computed`, `defineProps`, `defineEmits` |

#### vue-router ^4.5.0

| 项目 | 说明 |
|------|------|
| 用途 | SPA 路由管理，前后台路由隔离 + 权限守卫 |
| 在项目中的使用 | `router/index.ts` 配置 20 条路由规则，`FrontLayout`/`AdminLayout` 通过 `<router-view>` 渲染子页面 |
| 关键 import | `createRouter`, `createWebHistory`, `useRouter`, `useRoute` |

#### pinia ^2.3.0

| 项目 | 说明 |
|------|------|
| 用途 | 全局状态管理，仅存储用户/认证状态 |
| 在项目中的使用 | `stores/auth.ts` 管理 token/userUuid/username/isLoggedIn |
| 关键 import | `defineStore` |

### 2.2 网络请求

#### axios ^1.7.9

| 项目 | 说明 |
|------|------|
| 用途 | HTTP 请求库，封装统一的请求/响应拦截器 |
| 在项目中的使用 | `utils/request.ts` 封装实例（10s 超时 + Token 注入 + 401 拦截），5 个 API 模块均依赖此实例 |
| 关键 import | `axios`, `AxiosResponse` |

### 2.3 UI 组件库

#### element-plus ^2.9.2

| 项目 | 说明 |
|------|------|
| 用途 | 桌面端 UI 组件库，提供表单/表格/菜单/弹窗/分页等开箱即用的组件 |
| 在项目中的使用 | `main.ts` 全局注册；`AdminLayout.vue` 使用 `<el-menu>` 做侧边栏导航；`admin/login/index.vue` 使用 `<el-form>`/`<el-input>`/`<el-button>` 做登录表单；`useFormSubmit.ts` 使用 `ElMessage` 做 Toast 提示 |
| 当前使用组件 | `el-menu`, `el-menu-item`, `el-form`, `el-form-item`, `el-input`, `el-button` |
| 后续将使用 | `el-table`, `el-pagination`, `el-dialog`, `el-upload`, `el-select`, `el-tag`, `el-switch`, `el-breadcrumb` |
| 样式引入 | `import 'element-plus/dist/index.css'`（全量引入，后续可按需优化） |

#### @element-plus/icons-vue ^2.3.1

| 项目 | 说明 |
|------|------|
| 用途 | Element Plus 图标集合，用于侧边栏菜单图标、按钮图标等 |
| 当前使用 | 代码中暂未使用（占位阶段），后续在菜单和按钮中按需引入 |

## 五、安装与重置

### 首次安装

```bash
cd "D:\BaiduSyncdisk\Project(智能化气体传感器，工业火灾报警，和工业气体报警门户网站)\Code\frontend"
npm install
```

### 重新安装（清理后）

```bash
rd /s /q node_modules
del /f package-lock.json
npm install
```

### 安装检查

安装完成后可通过以下方式验证：

| 检查项 | 命令 | 预期结果 |
|--------|------|---------|
| Node 版本 | `node --version` | v22.19.0 |
| npm 版本 | `npm --version` | 10.9.3 |
| 核心依赖存在 | `npm ls vue` | vue@3.5.13 |
| 可正常启动 | `npm run dev` | Vite dev server running on localhost:5173 |

### 常见安装问题

| 问题 | 原因 | 处理 |
|------|------|------|
| `ERR_MODULE_NOT_FOUND` | 上次 `npm install` 被中断，`node_modules` 损坏 | `rd /s /q node_modules` 后重装 |
| `EBUSY: resource busy or locked` | 文件被占用 | 关闭 VS Code/终端，清理后重试 |
| `npm ERR! code EINTEGRITY` | package-lock.json 校验失败 | 删除 `package-lock.json` 后重装 |

## 六、不允许引入的依赖

| 依赖 | 禁止原因 |
|------|---------|
| **jQuery** | Vue 3 不依赖 DOM 操作库，增加包体积 |
| **Bootstrap JS** | 与 Element Plus 样式冲突，UI 风格不一致 |
| **Lodash** | 项目中目前无复杂数据处理需求，需要时按需引入具体函数 |
| **Day.js / moment.js** | 当前无日期处理需求，需要时引入 Day.js（轻量） |
| **Vuex** | 已统一使用 Pinia，Vuex 在 Vue 3 中属于遗留方案 |
