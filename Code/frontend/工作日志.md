### 数据流打通（6 大断点修复）

**问题：** 用户提交 / 管理员发布后目标页面看不到数据，数据未在用户、员工、管理员三个角色间正确流转。

**审计发现 6 个断点：**

| 断点 | 描述 |
|------|------|
| 1 | 用户提交工单 → 员工不可见 |
| 2 | 用户提交咨询 → 员工/管理员不可见 |
| 3 | 管理员发布内容 → 前台不可见 |
| 4 | 管理员发布新闻 → 新闻页不可见 |
| 5 | 产品详情页硬编码 IS-200 |
| 6 | Admin 列表页用本地 ref，未共享数据 |

**新建文件：**

| 文件 | 导出 |
|------|------|
| `src/data/content.ts` | `contents`（新闻/解决方案 reactive）、`adminProducts`（产品 reactive） |

**修改文件（12 个）：**

| 文件 | 修复内容 |
|------|---------|
| `user-tickets.vue` | `handleSubmit()` 写入 `workOrders[]` |
| `user-inquiries.vue` | `handleSubmit()` 写入 `messages[]` |
| `admin-product-list.vue` | 从 `adminProducts` 读取 |
| `admin-content-list.vue` | 从 `contents` 读取 |
| `admin-news-list.vue` | 从 `contents` 读取 |
| `admin-product-edit.vue` | 创建/编辑后写入 `adminProducts` |
| `admin-content-edit.vue` | 创建/编辑后写入 `contents` |
| `admin-news-edit.vue` | 创建/编辑后写入 `contents` |
| `content-list.vue` | 合并共享数据到 `allSolutions` |
| `news-detail.vue` | 合并共享数据到 `allNews` |
| `product-detail.vue` | 根据 `:uuid` 从 `adminProducts` 查找 |

**修复后数据流：**

```
用户端                      共享数据层                     管理端/前台
user-tickets  ----push-->  workOrders[]   <----read---- admin-workorder-list
user-inquiries---push-->  messages[]     <----read---- admin-message-list

admin-product-edit --push--> adminProducts[] <--read-- product-detail
admin-content-edit --push--> contents[]      <--read-- content-list
admin-news-edit    --push-->                 <--read-- news-detail
```

**验证：** `vue-tsc --noEmit` ✅ 通过 | `vite build` ✅ 构建成功（1822 modules）
